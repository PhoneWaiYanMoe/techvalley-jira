# TechValley — AI-Powered Issue Tracking Challenge

Welcome to the **Jira Lite MVP** coding challenge. Your task is to design, build, and deploy an AI-powered lightweight issue tracking web application.

## Getting Started

**All requirements, functional specifications, and evaluation criteria are defined in [`PRD.md`](./PRD.md).**

Read the PRD carefully before you begin. It covers:

- Core objectives and feature requirements
- Development workflow and Git guidelines
- Required tech stack (Next.js, Supabase, Vercel)
- Deployment and documentation expectations

Follow the PRD step by step as you work through the assignment.

## Quick Checklist

1. Clone this repository and create a branch from `main`: `dev/<your-name>`
2. Implement the application according to [`PRD.md`](./PRD.md)
3. Commit frequently (at least 5 meaningful commits per day)
4. Open a Pull Request to `main` when ready — **do not force push**
5. Never commit `.env` files or secrets (values will be provided separately)

For full details on setup, Git rules, environment variables, and submission, see **Section 2.1** in [`PRD.md`](./PRD.md).
